# AI 任务单记录

## 任务背景
我在配置 VS Code 的 Python 环境时遇到了困难，不知道怎么运行代码。

## AI 对话过程
**我的提问：**
如何在 VS Code 中配置并运行第一个 Python 脚本？

**AI 的回答：**
1. 首先去 Python 官网下载安装包，安装时勾选 "Add Python to PATH"。
2. 打开 VS Code，在左侧扩展商店搜索 "Python" 插件并安装。
3. 新建一个文件，命名为 hello.py，输入 print("Hello")。
4. 按 Ctrl+F5 或点击右上角运行按钮即可。

## 总结与结果
根据 AI 的指导，我成功配置了环境，并写了一个 `hello.py` 脚本，成功在终端打印出了 "Hello, World!"。


# 第一周：AI 任务单与反思

## 任务一：教案设计（对外汉语）
- **指令**：你是一位拥有10年经验的对外汉语教师，请为初级班学生设计一堂45分钟的“点餐”口语课教案。要求包含：教学目标、重点词汇（拼音+英文）、师生互动环节。请用表格形式输出。
- **输出摘要**：AI 给出了清晰的表格，包含了教学目标、词汇列表（如“菜单”、“点菜”、“服务员”等），以及角色扮演的互动环节。
- **一句反思**：给 AI 设定具体的“角色”和“输出格式（表格）”后，它的回答比直接问“怎么写点餐教案”要专业且有条理得多。

## 任务二：生词造句与语法解释
- **指令**：请用 HSK3 级学生能听懂的简单中文，解释“把”字句的用法。并给出3个生活中的例句，要求每个句子不超过10个字。最后附上一道单选题。
- **输出摘要**：AI 解释为“把东西放在动词前面”，例句给出了“我把苹果吃了”、“请把门关上”等。选择题也非常符合 HSK 风格。
- **一句反思**：如果不加“HSK3级”和“不超过10个字”的限制，AI 会写出非常生涩的长句。明确受众水平非常关键。

## 任务三：作文批改
- **指令**：请帮我批改下面这篇留学生中级作文。请先用一句话表扬优点，然后用表格列出语法和词汇错误，并给出修改建议，最后写一段鼓励性的总评。作文内容：[此处粘贴作文]。
- **输出摘要**：AI 首先表扬了“结构清晰”，然后用表格指出了“的/地/得”的混用，并给出了温和的总评。
- **一句反思**：AI 在批改时非常温柔，如果加上“请严厉一点，重点抓语法”的指令，可能会得到更精确的结果。
