# 第五周 课后作业

## 作业 1：Ollama 官方文档阅读笔记
重点阅读了 Model 管理与 API 文档，记录了 3 条我以前不知道的用法：
1. **自定义 Modelfile**：原来除了直接拉取官方模型，还可以自己写一个配置文件（Modelfile），在系统提示词里固定 AI 的人设（比如固定成“汉语老师”），这样就不用每次对话都重新输入一遍。
2. **参数 temperature 的传递**：以前以为只能在代码里改，看了文档才知道，在命令行里通过 `/set parameter temperature 0.5` 也可以直接调整模型的发散度。
3. **API 直连**：Ollama 启动后，默认在 `http://localhost:11434` 提供了一个兼容 OpenAI 格式的接口。这意味着我可以把以前写的 `llm.py` 里的 `base_url` 直接改成这个本地地址，完全无缝接入，非常方便。

## 作业 2：不同量级模型质量对比（0.5b vs 3b）
- **对比记录**：在同一个学科问题（“给《愚公移山》出一道 HSK4 阅读题”）下，`qwen2.5:0.5b` 模型回答极快（几乎秒出），但完全不按格式来，选项没写完就截断了，而且内容有明显的幻觉。而 `qwen2.5:3b` 模型虽然在首次加载时慢了几秒，但能完美输出完整的 A/B/C/D 四个选项，并且还附带了详细解析。
- **我的判断**：**质量提升绝对值得多占用的内存**。对于出题、批改、逻辑推理等教学核心任务，0.5b 是不可用的（容易误导学生）。3b 以上的模型虽然占用几 GB 内存，但它的回答达到了“可人工校验并直接使用”的标准。对于我的电脑配置来说，跑 3b 或 4b 模型是一个最佳的平衡点。

## 作业 3：《轻量级开源模型的离线部署》复盘
如果我要去一个完全无网、且电脑内存只有 8GB 的乡村学校教室部署 AI，我会这样准备：
1. **离线包准备**：提前用自己的电脑，下载好 Ollama 的 Windows 安装包（.exe）和模型的离线文件包。全部存入一个 U 盘，带到学校。
2. **模型选择**：考虑到学校电脑只有 8GB 内存，我会选择 `qwen2.5:1.5b` 或 `0.5b` 这种量化后极小（1GB左右）的模型。太大的模型会直接导致电脑卡死。虽然质量偏低，但完全能满足日常的格式转换、简单答疑等任务。
3. **内存预算**：教室电脑还要运行 PPT、浏览器等，系统本身会占掉 3-4GB 内存，留给 AI 的只有 4GB 左右。所以必须严格限制 `max_tokens` 等参数，防止内存溢出崩溃。
