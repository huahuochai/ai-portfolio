# 框架对照与反思

我选择了 **B 路径（阅读源码 + 改造点反思）**。

在阅读了 `smolagents` 框架的源码（`agents.py / tools.py`）后，我发现成熟框架确实把“解析 JSON”、“传递参数”、“多步循环”这些脏活累活全封装好了。

**我的改造点想法**：如果我要用 smolagents 改造我的助手，我会把我在 W9 写的 `query_hsk_level` 函数，直接加上 `@tool` 装饰器。这样，框架就能自动读取我的注释，生成 JSON 说明，我再也不用自己手写那一长串 `tools_schema` 了。这极大提高了开发效率。

**引用来源声明**：本次参考的 `smolagents` 框架基于 Apache-2.0 开源协议，允许学习和修改引用。
