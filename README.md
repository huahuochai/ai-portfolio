# 学科智能问答助手 v1.0

## 1. 项目简介
本项目集成了 W2 提示词、W6 双引擎、W7 知识库三大积木，通过 `use_rag` 开关，实现既能“纯对话”又能“基于资料回答”的智能助手。

## 2. 安装指南
运行 `pip install -r requirements.txt` 安装依赖。

## 3. 运行说明
运行 `python week08_助手v1.0/assistant_v1.py` 即可对话。

## 4. 效果展示
开启 RAG 后，模型会在本地知识库中检索相关教材再生成回答。

### 已知问题
目前使用本地 qwen2.5:3b 小模型，在遇到包含多个密集数字的资料时（如2245个词），容易受上下文干扰产生幻觉（如回答成500个）。

### 反思（200字）
为什么 README 里要诚实写“已知问题”？因为在工程开发中，诚实暴露问题比掩盖问题更重要。写明已知问题，一方面能让使用者降低不合理的预期，避免在实际教学场景中被错误答案误导；另一方面，它能清晰地指出项目当前的瓶颈（算力不足导致小模型幻觉）。这不仅是一份排错指南，更是项目下一步迭代的“引路灯”，提醒我们下周或未来需要将复杂的推理任务分发给云端 API 处理，也体现了我们严谨的工程态度。
