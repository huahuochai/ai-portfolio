# Function Calling / MCP / 普通 API 三者辨析

1. **Function Calling 是什么侧的机制，解决什么？**
   - **答案**：它是**模型侧**的机制。它解决的是“模型如何表达自己想调用哪个工具、需要什么参数”的问题，让大模型具备了调用外部函数的能力。

2. **MCP 是什么侧的协议，解决什么？**
   - **答案**：它是**协议侧（服务端与客户端之间）**的通信标准。它解决了“工具如何标准化、插拔式地提供给不同 AI 软件使用”的问题，就像 AI 界的 USB 接口。

3. **普通 API 调用和上面两个的本质区别是什么？**
   - **答案**：普通 API 是**写死在代码里的固定调用**，程序只能按预设的逻辑跑；而 Function Calling 和 MCP 是**由 AI 动态决定的**，AI 会自己判断“要不要调、调哪个、传什么参数”。
