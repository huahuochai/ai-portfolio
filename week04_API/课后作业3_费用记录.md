# 课后作业3：10次调用费用记录与判断

## 一、实测 Token 用量
根据上周实测，调用 DeepSeek 进行一次普通的学科问答（如“用一句话说明什么是把字句”），实际产生的 Token 用量为：
- **输入（Prompt）**：11 tokens
- **输出（Completion）**：49 tokens

## 二、费用估算（按 DeepSeek 官方计费规则）
- 输入单价约：1 元 / 百万 tokens
- 输出单价约：2 元 / 百万 tokens

**单次问答花费** = (11 × 0.000001) + (49 × 0.000002) ≈ **0.0001 元**
**10 次问答总花费** ≈ **0.001 元**（也就是一厘钱）。

*(注：如果问题更长、要求 AI 生成几百字的教案，一次调用约输出 300 tokens，单次花费约 0.0006 元，10 次总计也不到 1 分钱。)*

## 三、我的判断
“一次备课问答平均成本”几乎可以忽略不计。
作为一线教师，哪怕每天用 AI 高强度备课、提问 100 次，成本也才几毛钱。云端 API 的费用比买纸质教参便宜太多了，完全可以放心使用。

如果要在云端和本地之间做选择：
- **云端**：速度极快、回答质量高、按量付费（极便宜），适合日常备课。
- **本地**：不花钱，但需要占用电脑内存。适合处理学生隐私数据。
