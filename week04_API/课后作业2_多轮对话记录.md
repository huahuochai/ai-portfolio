# 课后作业2：多轮对话测试记录

## 测试方法
我在代码中引入了 `history_messages = []` 列表。每次向 API 发送请求时，把历史对话（`{"role": "user", ...}` 和 `{"role": "assistant", ...}`）追加到这个列表中，并将整个列表作为 `messages` 参数传给 API。这样模型就能“记住”之前聊了什么。

## 测试过程与结果
- **第一轮提问**：“我想写一篇关于《愚公移山》的教案，帮我列两个教学目标。”
  - **AI回答**：列出了目标一（积累文言基础知识）和目标二（分析人物形象）。
- **第二轮提问**：“把刚才的**第一个目标**扩写成一段具体的教学活动。”
  - **AI回答**：准确理解了“刚才的第一个目标”是指“积累文言基础知识”，并围绕《愚公移山》设计了“词义抢答”、“句译接力”等教学活动。

## 结论
程序成功实现了多轮记忆。如果没加历史记录，第二轮提问 AI 会不知道“刚才”指的是什么，导致答非所问。加入 `messages` 历史列表后，程序拥有了上下文连贯性，体验非常顺滑。
