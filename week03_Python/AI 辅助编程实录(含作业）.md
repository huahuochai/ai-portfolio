# AI 辅助编程实录：生词表练习生成工具

## 一、 我的初始提示词
> "请帮我写一个 Python 脚本。它需要读取当前目录下的 `生词表.csv` 文件，过滤出等级为 HSK4 的词汇，并统计每种词性有多少个。最后，把这些 HSK4 的词汇生成一个填空题的文本文件 `练习.txt`，格式为：用 '[词汇]' 造一个句子。（[词性]）。"

## 二、 AI 初版代码的问题
AI 第一版代码使用了 `pandas` 库。但我本地环境没装，导致报错。而且直接生成的中文在 `.txt` 里可能变成乱码。

## 三、 我的修改点
> "请不要用 pandas，只用 Python 自带的 `csv` 模块。另外，写入文件时必须在 `open()` 里面加上 `encoding='utf-8'`，否则中文乱码。"

## 四、 最终版差异说明
1. **去除了第三方依赖**：改用原生的 `csv.DictReader`，无需安装额外库，直接就能跑。
2. **解决了乱码**：加了 `encoding='utf-8'`，中文完美显示。
3. **路径自适应**：加入了 `os.path` 获取当前脚本目录，这样不管在终端怎么运行，都能准确找到文件。
